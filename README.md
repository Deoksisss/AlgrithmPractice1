## ✨ Возможности приложения

- 📊 **14 алгоритмических кейсов** (векторы, матрицы, теория чисел, возведение в степень).
- 📈 **Аппроксимация МНК**: автоматический подбор масштабного коэффициента $C$ для теоретической функции сложности $f(n)$ и расчёт $MSE$.
- 🧊 **Интерактивные 3D-графики**: построение трехмерной поверхности $(n, m, \text{время})$ для матричного умножения с поддержкой орбитального вращения мышью и зума.
- 💾 **Кэширование в SQLite**: уникальный составной ключ `(AlgorithmId, ConfigHash)` (SHA-256 хэш параметров) позволяет мгновенно загружать ранее вычисленные результаты без повторных тяжёлых расчётов.
- 🔄 **Пакетный запуск и живой прогресс**: очередь задач с индикатором выполнения $N/M$, прогресс-баром и дифференцированными статусами (`В очереди`, `Выполняется`, `Готово (посчитано)`, `Готово (из кэша)`).
- 🔍 **Режим сравнения сессий**: одновременное наложение серий данных из разных сессий на одном полотне графика с индивидуальными цветами и пунктирными линиями аппроксимаций.

## 🔬 Исследуемые алгоритмы

| № | Название | Категория | Метрика | Сложность $f(n)$ | Описание |
|---|----------|-----------|---------|-------------------|----------|
| 1 | **Постоянная функция** | Часть I. Векторы | Время (мс) | $O(1)$ | $f(v) = 1$ |
| 2 | **Сумма элементов** | Часть I. Векторы | Время (мс) | $O(n)$ | $\sum v_i$ |
| 3 | **Произведение элементов** | Часть I. Векторы | Время (мс) | $O(n)$ | $\prod v_i$ |
| 4 | **Полином (наивный)** | Часть I. Векторы | Время (мс) | $O(n^2)$ | $\sum a_k x^k$ с повторным вычислением степеней |
| 5 | **Полином (схема Горнера)** | Часть I. Векторы | Время (мс) | $O(n)$ | Оптимальное вычисление полинома |
| 6 | **Пузырьковая сортировка** | Часть I. Векторы | Время (мс) | $O(n^2)$ | Bubble Sort массива случайных чисел |
| 7 | **Быстрая сортировка** | Часть I. Векторы | Время (мс) | $O(n \log n)$ | QuickSort с разбиением Хоара |
| 8 | **Сортировка TimSort** | Часть I. Векторы | Время (мс) | $O(n \log n)$ | Стандартная системная `Array.Sort` |
| 9 | **Матричное умножение** | Часть II. Матрицы | Время (мс) | $O(n^2 m)$ | $A(n \times m) \times B(m \times n)$, **3D график** |
| 10 | **Гномья сортировка** | Часть III. Индивидуальные | Время (мс) | $O(n^2)$ | Gnome Sort |
| 11 | **Факторизация Полларда «Ро»** | Часть III. Индивидуальные | Время (мс) | $O(N^{1/4})$ | $N = p \cdot q$, где $n$ — **битовая длина числа $N$** |
| 12 | **Тест простоты Миллера–Рабина** | Часть III. Индивидуальные | Время (мс) | $O(k \log^3 N)$ | Тест простоты, $n$ — **битовая длина числа**, $k$ — раунды |
| 13 | **Итеративное возведение в степень** | Часть IV. Степень | **Количество шагов** | $O(n)$ | $n-1$ операций умножения |
| 14 | **Рекурсивное возведение в степень** | Часть IV. Степень | **Количество шагов** | $O(n)$ | $x^n = x \cdot x^{n-1}$, $n-1$ операций |
| 15 | **Бинарное возведение в степень** | Часть IV. Степень | **Количество шагов** | $O(\log n)$ | Быстрое возведение за $\lfloor \log_2 n \rfloor$ умножений |

## 🏛️ Архитектура и проектные решения

```
AlgorithmPractice1.sln
├── src/
│   ├── AlgorithmPractice1.Core/            # Доменная модель, алгоритмы, МНК, репозитории, SQLite, BenchmarkDotNet
│   ├── AlgorithmPractice1.GUI/             # Avalonia UI (MVVM, Views, ViewModels, Services)
│   └── external/
│       └── AvaloniaChartsLib/              # Библиотека визуализации 2D и 3D графиков
└── tests/
    └── AlgorithmPractice1.Core.Tests/      # xUnit тесты (алгоритмы, МНК, кэш, БД)
```

### 1. Трактовка $n$ для алгоритмов теории чисел
- **Миллер–Рабин (`MillerRabin`)**: $n$ — разрядность числа в битах (например, 16–128 бит). Параметр $k$ (число раундов) настраивается отдельно (по умолчанию $k=20$).
- **Метод Полларда «Ро» (`PollardRho`)**: $n$ — битовая длина составного числа $N = p \cdot q$, где $p, q$ — случайные простые числа длины $\approx n/2$ бит.

### 2. Точные замеры и warmup
- Замеры выполняются через `System.Diagnostics.Stopwatch.GetTimestamp()` с предварительным прогревом (`WarmupRuns = 1`), принудительной сборкой мусора (`GC.Collect()`) перед сериями замеров и усреднением по независимым прогонам на каждый размер $n$.
- Дополнительно интегрирован пакет **BenchmarkDotNet** (`InProcessNoEmitToolchain`) для проведения эталонных измерений.

### 3. МНК-аппроксимация и MSE
- Расчёт масштабного коэффициента $C$ аппроксимирующей кривой $T_{approx}(n) = C \cdot f(n)$:
  $$C = \frac{\sum_{i=1}^{k} T_i \cdot f(n_i)}{\sum_{i=1}^{k} (f(n_i))^2}$$
- Среднеквадратичная ошибка (MSE):
  $$MSE = \frac{1}{k} \sum_{i=1}^{k} (T_i - C \cdot f(n_i))^2$$
- Значение MSE отображается в легенде графика: `Аппроксимация (MSE: 1.45e-05)`.

### 4. Кэширование и SQLite
- База данных `algorithm_practice.db` инициализируется автоматически при первом запуске.
- Ключ кэша: `(AlgorithmId, SHA256(NMax, NStep, RunsPerN, M, K, X))`.
- При `ForceRecalculate == false` повторные эксперименты с идентичными параметрами загружаются мгновенно.

## 🖥️ Интерфейс пользователя (GUI)

Интерфейс построен на **Avalonia UI** (светлая тема в стиле GitHub / Fluent Design) и состоит из трех основных вкладок:

1. **⚙️ Настройка эксперимента (`ExperimentSetupView`)**:
   - Выбор алгоритмов (одиночный, групповой, «Выбрать все»).
   - Индивидуальная настройка $N_{max}$, шага, числа повторений и специфичных параметров ($M$ для матриц, $K$ для теста Миллера-Рабина, $X$ для основания степени).
   - Чекбокс принудительного пересчёта (обход кэша).
   - Опциональное поле метки сессии и кнопка «🚀 Запустить эксперимент».

2. **⏳ Прогресс выполнения (`ExperimentProgressView`)**:
   - Живой индикатор $N/M$ и шкала прогресса.
   - Список выполняемых задач с индикацией этапов (в очереди, замер времени, сохранение, кэш).
   - Кнопка перехода к результатам после завершения пакета.

3. **📈 Результаты и история (`HistoryView`)**:
   - Боковая панель со списком всех проведённых сессий (дата, название, количество алгоритмов).
   - Одиночный режим с разворачиваемыми карточками (`Expander`) по каждому алгоритму.
   - Режим сравнения: при выборе нескольких сессий чекбоксами графики объединяются для наглядного сопоставления результатов.

## 🚀 Быстрый старт и запуск

### Требования
- [.NET 8.0 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) или новее.
- Windows 10/11, Linux или macOS.

### Сборка
```bash
git clone https://github.com/Deoksisss/AlgorithmPractice1.git
cd AlgorithmPractice1
dotnet build AlgorithmPractice1.sln
```

### Запуск GUI
```bash
dotnet run --project src/AlgorithmPractice1.GUI/AlgorithmPractice1.GUI.csproj
```

## 🧪 Тестирование

Проект покрыт автоматическими тестами на xUnit (`AlgorithmPractice1.Core.Tests`):
- Корректность работы всех 14 алгоритмических кейсов.
- Сравнение результатов наивного полинома и схемы Горнера.
- Факторизация Полларда и тест Миллера–Рабина.
- Подсчёт шагов в алгоритмах возведения в степень.
- Корректность формул МНК и MSE на синтетических данных.
- Детерминированность `ConfigHash` и логика кэширования SQLite.

Запуск тестов:
```bash
dotnet test AlgorithmPractice1.sln
```
